# herd

牧羊犬を操作して羊の群れを導くブラウザゲーム。

## 操作

| 操作 | 内容 |
| --- | --- |
| マウス / タッチ(ドラッグ) | 犬を動かす |
| WASD / 矢印キー | 犬を動かす |
| クリック / Space / 「ワン!」ボタン | 吠える(周りの羊を驚かせる) |
| R | リセット |
| V | 内部状態の表示(逃走距離・警戒距離・吠え声の届く範囲・羊の状態) |
| P / 「⚙ 調整」ボタン | パラメータ調整モード(URL に `?tune` を付けても開く) |
| O | 自動で追う(デモ用) |

## 羊の動き

boid(分離・整列・結合)を土台に、羊らしさを足している(`src/sim.ts`)。

- **graze / walk**: ふだんはほぼ止まって草を食み、ときどき数歩歩く。歩く仲間につられて歩き出す
- **alert**: 犬が警戒距離に入ると顔を上げ、犬を気にしながらじわじわ離れる
- **flee**: 犬が逃走距離に入ると走って逃げる。犬が速く迫るほど逃走距離は広がる。怖いほど群れの中心に潜り込み(selfish herd)、向きを揃える
- **恐怖の伝染**: 恐怖は近くの仲間に伝わるので、犬から遠い羊も一緒に動く。落ち着くには時間がかかる
- **慣性**: 加速と旋回の速さに上限があり、怖いほど機敏になる

## パラメータ調整モード

群れ方・速さ・犬への反応などを画面から調整できる。

- 変えた値は黄色で示され、↺ で項目ごとに初期値へ戻せる
- 変更はブラウザ(localStorage)に保存され、再読み込みしても残る
- 「書き出し」で初期値から変えた値だけを JSON にしてコピーできる。決まった値は `src/sim.ts` の `defaultParams` に反映する

## 構成

- `src/sim.ts` — シミュレーション(DOM に依存しない。テスト対象)
- `src/bot.ts` — 牧羊の自動操作(テストとデモ用)
- `src/render.ts` — Canvas 2D の描画
- `src/tuning.ts` — パラメータ調整パネル
- `src/main.ts` — 入力・ループ・UI

## 開発

```sh
npm install
npm run dev        # 開発サーバー (http://localhost:5173)
npm test           # ユニットテスト (Vitest)
npm run build      # 型チェック + 本番ビルド (dist/)
npm run preview    # ビルド結果の確認
```

## デプロイ

`main` への push で GitHub Actions がテスト・ビルドし、GitHub Pages にデプロイする。
初回はリポジトリの Settings → Pages → Source を **GitHub Actions** にしておく。
